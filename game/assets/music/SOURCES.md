# Music sources

## Coop dynamic soundtrack

The five source loops were created by **Antronical** and downloaded from
Looperman on 2026-08-31. Each source is 16 seconds, 120 BPM, stereo PCM WAV at
44.1 kHz. The melodic loops are in A minor and were published as a compatible
set.

| In-game stem | Original file | Source |
| --- | --- | --- |
| `coop/drums.ogg` | `looperman-l-1098170-0400883-coop-drums.wav` | [Coop Drums](https://www.looperman.com/loops/detail/400883/coop-drums-free-120bpm-electronic-drum-loop) |
| `coop/synth.ogg` | `looperman-l-1098170-0400879-coop-synth.wav` | [Coop Synth](https://www.looperman.com/loops/detail/400879/coop-synth-free-120bpm-pop-synth-loop) |
| `coop/rhodes-stabs.ogg` | `looperman-l-1098170-0400880-coop-rhodes-stabs.wav` | [Coop Rhodes Stabs](https://www.looperman.com/loops/detail/400880/coop-rhodes-stabs-free-120bpm-rnb-rhodes-piano-loop) |
| `coop/rhodes-line.ogg` | `looperman-l-1098170-0400881-coop-rhodes-line.wav` | [Coop Rhodes Line](https://www.looperman.com/loops/detail/400881/coop-rhodes-line-free-120bpm-rnb-rhodes-piano-loop) |
| `coop/pad.ogg` | `looperman-l-1098170-0400882-coop-pad.wav` | [Coop Pad](https://www.looperman.com/loops/detail/400882/coop-pad-free-120bpm-weird-synth-loop) |

The WAV files were converted to Ogg Vorbis quality 7 for the game. No tempo,
pitch or musical-content changes were made.

users to incorporate loops into new compositions used in computer games. The
loops may not be redistributed as a standalone sample library. See the
